# AI Disclosure

## AI tools used in building this project
- **Claude (Anthropic)** was used to generate the prototype source code (HTML, CSS, JavaScript), the README, and this disclosure, based on the team's submission deck and design brief.

## AI inside the prototype
- None. The prototype contains **no LLM or cloud AI calls**. Applicability decisions are made by deterministic JavaScript code. All processing runs in the browser; no user data leaves the device.

## Human contribution
- The concept, problem statement, architecture and Samsung Care policy scenario come from the team's PRISM submission deck.
- The team reviewed, ran and is responsible for the submitted code.

## Data
- The Samsung Care clauses in `source-code/data/clauses.js` are illustrative sample data written for the demo, not official Samsung policy text.
